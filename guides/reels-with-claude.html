Reels With Claude: prompts

Tap Copy, paste into Claude, and replace the [brackets] with your details.

STEP 1 · SETUP

1. Make a folder called "AI Video Editor" in Documents.
2. Download the Claude desktop app: claude.com/download (not the browser, it can't install software).
3. Open the app → Code tab → choose your AI Video Editor folder.

Then paste the prompts below one by one. Replace the [brackets] with your own details. 👇

PROMPT 1 · INSTALL

I want to make Instagram Reels (1080x1920 videos) with code, inside this folder. Set everything up for me, step by step:
1. Check my computer (Mac or Windows) and install whatever is missing: Node.js (LTS), FFmpeg and Python 3.
2. Create a Remotion project in this folder (TypeScript, blank template).
3. Install the free, offline Kokoro text-to-speech voice in a Python virtual environment.
4. Install Whisper (whisper.cpp or openai-whisper) so we can make word-timed captions.
5. Test each tool with a tiny example and show me a checklist of what is installed.
Explain each step in simple words. Ask me before anything that needs my password.

PROMPT 2 · SCRIPT

Write a 45–60 second Instagram Reel script about: [YOUR TOPIC]
(No topic? Suggest 3 funny comedy topics for an Indian audience, then write the script for the best one.)
Rules:
- Language: [Hinglish / Hindi / English], short sentences, max 150 words
- Hook in the first 3 seconds (curiosity or a surprising true fact)
- 5–8 short scenes, one idea each
- End with: "Comment [KEYWORD] and I'll DM you ..."
Give me: the voice lines (for Hindi, write Hindi words in Devanagari and English words in English letters), the on-screen text for each scene, and a list of every fact with its source. Mark anything you can't verify.

PROMPT 3 · VOICE

Make the voiceover for this script with the free Kokoro voice we installed.
Language: [Hindi / English]. Pick a natural voice (for Hindi try hm_omega or hf_alpha), speed about 1.1–1.2 so every word is clear.
- Read the script exactly, word for word. Don't add or skip words.
- Make one audio file per scene and one full voiceover.
- Then run Whisper on it and compare with the script. If any word sounds wrong, add a pronunciation fix and make it again.
- Save the word timings for the captions.

BONUS · CHARACTER

Create a 2D cartoon presenter for my reels as a React/SVG component in this Remotion project. Pure code, no images.
Look: [describe yourself: hair, glasses, beard, clothes and colours]
He should:
- blink every few seconds
- move his mouth in sync with the voiceover (use the word timings or the audio volume)
- use simple hand gestures: wave, point, thumbs-up, counting on fingers
Show me a preview image with 4 poses so I can approve the look before we use it.

PROMPT 4 · BUILD

Build the reel in Remotion from the approved script, voiceover and character.
- 1080x1920, 30 fps, length = the voiceover length
- One scene per script line, each with an animation (slide, pop, zoom or typing)
- Word-by-word captions synced to the voice, with the current word highlighted
- The character at the bottom, talking during the voice
- Big, readable text. Brand colours: [your colours]. Handle: [@yourhandle]
- Last scene: a "Comment [KEYWORD]" box
Open the preview (Remotion Studio) only. Don't render until I say "render now".

STEP 7 · CHANGES

Watch the preview and just say what to change, in plain words:
• make the hook punchier
• it's day, make it night
• make the captions bigger
• make the character smaller so he doesn't cover the text

STEP 8 · RENDER
render now. Save the final MP4 in an "Exports" folder, plus a cover image (PNG) and an Instagram caption with hashtags in a .txt file.

Watch it once with sound, then upload. 🎬
